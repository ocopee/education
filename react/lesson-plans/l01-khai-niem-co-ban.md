#  React và bản chất cơ bản

## Bản chất của react có 3 ý chính như sau:
- Html ở trong react nó không phải là `html thuần` mà là được js của react render ra. 
- `Jsx` là `js` trong react,  có nhiều công cụ để hỗ trợ dịch react sang `js thuần`, vì cái mình đang nhìn không phải `js thuần` ( ví dụ đang lồng return html)
- `Tag` của react có 2 cách viết là `class component` và `function component`, nhưng hiện tại mình chỉ tìm hiểu về `function component`

Note: `react` sau khi thành `js thuần` thì nó sẽ có cơ chế sinh ra html mà không cần sườn html, nhưng mà cần ít nhất 1 page trống để import js đó vào, còn jquery thì cần có 1 sườn html và inport đoạn js của nó vào để nó sử lý
